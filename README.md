1. Python To-Do List Project

A simple command-line To-Do List application built in Python.  
This project helps you practice **file handling, loops, and exception handling** while managing tasks.

---

2. Features
- Add new tasks 
- View all tasks 
- Delete tasks 
- Persistent storage using `tasks.txt`
